3Un valor que no es un número12 min

Qué estás mirandomalformed_example_1_data.csv tiene un transactions_timestamp que vale aaa. Si dejas que se infiera el esquema, una sola fila mala convierte toda la columna en texto. Si fijas el esquema, la columna es BIGINT y la fila mala no se pierde: su valor original va a _rescued_data.

  2. SQL

    Deberías verUna columna, value, con 5 filas: la cabecera order_id|email|transactions_timestamp y cuatro pedidos. El primero termina en |aaa.
  3. SQL
    %sql
SELECT *
FROM read_files(
        '/Volumes/lab0504/upload/upload/csv-demo-files/malformed_example_1_data.csv',
        format => "csv",
        sep => "|",
        header => true
      );
    Deberías ver4 filas, y transactions_timestamp como STRING: el aaa ha impedido que se infiera como número.
  4. SQL
    %sql
SELECT *
FROM read_files(
        '/Volumes/lab0504/upload/upload/csv-demo-files/malformed_example_1_data.csv',
        format => "csv",
        sep => "|",
        header => true,
        schema => '''
            order_id INT,
            email STRING,
            transactions_timestamp BIGINT''',
        rescuedDataColumn => '_rescued_data'
      );
    Deberías ver4 filas. La del pedido 298592 tiene transactions_timestamp a NULL y el aaa dentro de _rescued_data; las otras tres, su timestamp y _rescued_data a NULL.
    5. Comprueba que lo has entendido¿Por qué aquí hay que pedir rescuedDataColumn? Con el esquema inferido, read_files añade _rescued_data sola; con un esquema explícito, no. Sin la opción, el aaa desaparecería sin avisar y solo quedaría un NULL.
    Si algo fallaSi la última consulta falla con un error de sintaxis, revisa las tres comillas simples ''' que abren y cierran el esquema. Si sigue sin funcionar, salta al bloque 4.

4Una cabecera incompleta10 min

Qué estás mirandoA malformed_example_2_data.csv le falta el nombre de la primera columna en la cabecera. Los datos están bien, pero sin nombre la columna no puede ser una columna normal: Databricks la rescata entera y la guarda con la clave _c0.

    %sql
SELECT
  cast(_rescued_data:_c0 AS BIGINT) AS order_id,
  *

        format => "csv",
        sep => "|",
        header => true
      );
    Por qué esto: extrae un campo de un texto JSON y siempre devuelve texto; por eso el cast a BIGINT.
