2Decodificar el Base648 min

Qué estás mirandoKafka transporta los mensajes como bytes, y al exportarlos a JSON se codifican en Base64 para que quepan en un texto. Deshacerlo tiene dos pasos: unbase64() devuelve los bytes (BINARY) y cast(… AS STRING) los convierte en texto.
  1. Deberías verdecoded_key y decoded_value de tipo BINARY: todavía no se leen.
  2. SQL
    SELECT
  key AS encoded_key,
  cast(unbase64(key) AS STRING) AS decoded_key,
  value AS encoded_value,
  cast(unbase64(value) AS STRING) AS decoded_value
FROM kafka_events_bronze_raw
LIMIT 5;
    Deberías verdecoded_key legible (un identificador como UA00000000000000, el mismo que el user_id) y decoded_value como texto JSON: {"device":"Chrome","ecommerce":{…},…}.
  3. Deberías verSeis columnas, ya legibles. Sigue habiendo 2.252 filas: decodificar no añade ni quita eventos.
    4. Si algo fallaSi decoded_value sale como bytes y no como texto, falta el cast(… AS STRING). Si sigue sin funcionar, salta al bloque 3.

  1. SQL

    Deberías verCinco compras (finalize) con su ciudad e items como un texto con el array de artículos.
  3. Deberías verNueve columnas: las cinco del sobre más device, traffic_source, geo e items, todas STRING.

4El JSON como STRUCT y explode12 min

Qué estás mirandoUn STRUCT es un JSON con esquema fijo: cada campo tiene su tipo. Para crearlo, primero obtienes el esquema con schema_of_json() y después lo aplicas con from_json(). Con el array items ya tipado puedes convertir cada artículo en una fila con explode().
  1. Por qué estoSe aplica a una compra con todos los campos rellenos. Con un evento de items vacío o con campos a null, el esquema saldría incompleto o con tipos equivocados.
    Deberías verUna fila con un texto largo que empieza por STRUCT<device: STRING, ecommerce: STRUCT<… y contiene items: ARRAY<STRUCT<coupon: STRING, ….
  2. Deberías verSeis columnas, la última, value, de tipo STRUCT: puedes desplegarla y ver ecommerce, geo e items dentro.
  3. SQL
    SELECT
  decoded_key,
  value.device as device,
  value.geo.city as city,
  value.items as items,
  array_size(items) AS number_elements_in_array
FROM kafka_events_bronze_struct
ORDER BY number_elements_in_array DESC;
    Deberías verArriba, 103 compras de 3 artículos; luego 197 de 1, 1.902 eventos con 0 y, al final, 50 con NULL (los que traen items: null).
  4. Deberías ver506 filas: una por artículo. Cada compra de 3 artículos aparece 3 veces con un item_in_array distinto.
  5. SQL
    SELECT
  (SELECT count(*) FROM (SELECT explode(value.items) FROM kafka_events_bronze_struct))       AS filas_explode,
  (SELECT count(*) FROM (SELECT explode_outer(value.items) FROM kafka_events_bronze_struct)) AS filas_explode_outer;
    Deberías verfilas_explode = 506 y filas_explode_outer = 2.458.
    6. Comprueba que lo has entendido¿De dónde salen las 1.952 filas de diferencia? Son los eventos sin artículos: explode() no genera filas para un array vacío o nulo, y explode_outer() genera una con NULL para cada uno. Si pierdes esos eventos al explotar, también pierdes sus visitas.
    Si algo fallaSi el CTAS con from_json da error, el esquema pegado está incompleto: copia la celda de nuevo desde el notebook original. Si sigue sin funcionar, salta al bloque 5.

5El JSON como VARIANT8 min

Qué estás mirandoVARIANT guarda el JSON con su estructura y sin esquema fijo: no hay que calcular ni pegar nada, y aun así se consulta rápido. Con : obtienes otro VARIANT, y con :: lo conviertes al tipo que quieras.
  1. Deberías verLa tabla kafka_events_bronze_variant con una columna json_variant_value de tipo VARIANT.
  2. SQL
    SELECT
  json_variant_value,
  json_variant_value:device :: STRING,
  json_variant_value:items
FROM kafka_events_bronze_variant
LIMIT 10;
    Deberías verdevice como STRING (Chrome, Linux…) e items como VARIANT.
    3. Comprueba que lo has entendidoMismo campo, tres formas: decoded_value:device devuelve siempre texto; value.device, el tipo del esquema que pegaste; json_variant_value:device, un VARIANT que conviertes con ::.
    Si algo fallaSi parse_json da un error de tipo no soportado, tu entorno Serverless es la versión 1: cámbialo en el panel Environment. Si sigue sin funcionar, salta al bloque extra.
