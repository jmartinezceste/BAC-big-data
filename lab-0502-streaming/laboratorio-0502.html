2Crear la streaming table10 min

Qué estás mirandoUna streaming table es una tabla de Unity Catalog que se mantiene al día de forma incremental: en cada refresco solo procesa lo nuevo. Al crearla, Databricks monta por ti un pipeline serverless que hace el trabajo; no consume el cómputo de tu notebook. Es la alternativa recomendada al COPY INTO del laboratorio 0501.
  1. SQL
    %sql
CREATE OR REFRESH STREAMING TABLE sql_csv_autoloader
SCHEDULE EVERY 1 WEEK     -- Programar el refresco es opcional
AS
SELECT *
FROM STREAM read_files(
  '/Volumes/lab0502/upload/upload',
  format => 'CSV',
  sep => '|',
  header => true
);
    Por qué estoSTREAM delante de read_files es lo que la hace incremental: el lector recuerda qué ficheros ha procesado. SCHEDULE la refrescaría sola cada semana.
  2. Deberías verLa tabla sql_csv_autoloader, con un icono distinto al de una tabla normal: una tabla con unas ondas.
  3. SQL
    %sql
SELECT *
FROM sql_csv_autoloader;
    Deberías ver3.149 filas.
  4. SQL

    Deberías verEn Detailed Table Information, Type indica que es una streaming table y Provider = delta. Más abajo, Refresh Information con el último refresco y la programación semanal.

+Extra: Auto Loader en Python15 min

Qué estás mirandoAuto Loader también se escribe en Python, con Structured Streaming y el formato cloudFiles. Necesita una carpeta de checkpoint, donde apunta qué ficheros ha procesado. Ojo con una diferencia clave: con trigger(availableNow=True) el stream procesa lo que hay y se para. La tabla no se actualiza sola cuando llegan ficheros: hay que volver a ejecutar la celda. Este bloque es material extra: hazlo si te sobra tiempo.
  1. Deberías verEl mismo mensaje del bloque 0: Entorno listo … contiene solo 000.csv con 3149 filas.
  2. Deberías verSolo 000.csv.
  3. Python
    %python
checkpoint_file_location = '/Volumes/lab0502/streaming/checkpoints/python_csv_autoloader'

(spark
 .readStream
   .format("cloudFiles")
   .option("cloudFiles.format", "csv")
   .option("header", "true")
   .option("sep", "|")
   .option("inferSchema", "true")
   .option("cloudFiles.schemaLocation", f"{checkpoint_file_location}")
   .load("/Volumes/lab0502/upload/upload/")
 .writeStream
   .option("checkpointLocation", f"{checkpoint_file_location}")
   .trigger(availableNow=True)
   .toTable("lab0502.streaming.python_csv_autoloader")
 .awaitTermination()
)
    Por qué estoavailableNow=True procesa lo pendiente y se para. El trigger(once=True) de muchos tutoriales hace lo mismo, pero está deprecado y Serverless no lo admite.
    Deberías verLa celda termina sola al cabo de unos segundos: no se queda escuchando.
  4. Deberías ver3.149 filas y todas las columnas como texto, aunque el código pide inferSchema. Auto Loader ignora esa opción; para inferir tipos se usa cloudFiles.inferColumnTypes.
  5. Deberías verDos ficheros en el volumen: 000.csv y 001.csv.
  6. SQL
    %sql
SELECT count(*) AS filas
FROM lab0502.streaming.python_csv_autoloader;
    Deberías verSiguen siendo 3.149. El fichero nuevo está en el volumen, pero el stream del paso 2 ya terminó y nadie lo ha procesado.
  7. Deberías verLa celda termina sin error. Gracias al checkpoint, esta vez solo lee el fichero nuevo.
  8. Deberías ver6.081 filas y dos STREAMING UPDATE en el historial, uno por cada vez que ejecutaste el stream: 3.149 filas el primero y 2.932 el segundo.
    9. Comprueba que lo has entendidoSi mañana llega 002.csv, ¿entrará en la tabla? No, hasta que alguien vuelva a ejecutar el stream. En producción esa celda se programa como tarea de un job (tema 10). En la parte SQL pasa lo mismo: la streaming table no se refrescaba hasta el REFRESH, salvo por su SCHEDULE semanal.
  9. SQL
    %sql
DROP TABLE IF EXISTS lab0502.streaming.python_csv_autoloader;
    10. Si algo fallaSi el stream falla con trigger type not supported, la celda usa once=True: cámbialo por availableNow=True. Si tras relanzar el stream la tabla sigue en 3.149 filas, comprueba que 001.csv está en el volumen y que usas el mismo checkpoint_file_location. Si sigue sin funcionar, no pasa nada: es material extra y el laboratorio está completo con los bloques anteriores.
